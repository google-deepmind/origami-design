Add Your Origami Model to the Gallery

You can preview any local .fold, .svg, or stick_figure.json immediately via Open Model (or drag-and-drop onto this page). To contribute a model permanently to the open-source showcase: 

# 1. Design & shape your stick figure with bp-pipeline:
uv run bp-pipeline my_creature.json -o outputs/my_creature

# 2. Build the static web bundle under docs/models/<slug>/:
python3 scripts/build_showcase_bundles.py \
  --input outputs/my_creature \
  --slug my-creature \
  --title "My Origami Creature"

# 3. Preview locally at http://localhost:8000 & open a Pull Request:
python3 -m http.server 8000 -d docs
